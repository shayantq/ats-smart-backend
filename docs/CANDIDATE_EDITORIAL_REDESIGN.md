# بازطراحی داشبورد کارجو

داشبورد کارجو با سیستم بصری پنل منابع انسانی هماهنگ شد: رنگ‌های خنثی، جداکننده‌های ظریف، فونت محلی Vazirmatn و چیدمان دو ستونه در دسکتاپ و تک ستونه در موبایل. پروفایل و مهارت‌ها، ارسال رزومه، پیگیری درخواست‌ها و صندوق پیشنهادها پوشش داده شده‌اند. کنترل فایل دکمهٔ قابل دسترس دارد و تب‌ها با کلیدهای جهت در RTL و Home/End کار می‌کنند.

قرارداد API، احراز هویت، منطق مراحل استخدام، پاسخ پیشنهاد و تأیید دومرحله‌ای حذف حساب تغییر نکرده‌اند. وابستگی یا سرویس جدیدی اضافه نشده است.

## راستی‌آزمایی محلی

- `cd frontend; npm run build`: موفق.
- `cd frontend; npm test -- --runInBand`: ۳۷ تست در ۱۰ مجموعه موفق.
- `node frontend/candidate-editorial-check.cjs after`: سه عرض ۳۷۵، ۷۶۸ و ۱۴۴۰ بدون سرریز افقی صفحه یا خطای جاوااسکریپت؛ ناوبری تب‌ها و کاهش حرکت موفق.
- حالت‌های پر و خالی، عنوان فارسی طولانی و مهارت انگلیسی بدون فاصله با دادهٔ کاملاً ساختگی بررسی شدند. تصاویر از این داده‌ها مدرک کیفیت مدل یا دادهٔ واقعی استخدام نیستند.
- ورود واقعی حساب آزمایشی کارجو و دریافت پروفایل از API محلی نیز موفق بود.

سرریز موجود قبل از تغییر در عرض‌های ۳۷۵ و ۷۶۸ برطرف شد. تغییرات این مرحله محلی‌اند و هنوز push یا deploy نشده‌اند. بررسی دستی صفحه‌خوان و دستگاه موبایل فیزیکی انجام نشده است.
